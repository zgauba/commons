## Code review — APPROVE with warnings (0 critical / high, 3 medium, 4 low)
| # | Finding | Disposition |
|---|---|---|
| M1 | Zoom tapped before the photo loads → "zoomed" state, 1× photo, taps no longer close | Fixed — `jcPvZoom` does nothing until the image exists |
| M2 | `aria-pressed` plus a label that flips ("Zoom In" / "Zoom Out") reads as a double negative | Fixed — one label "Zoom" / «تكبير», state in `aria-pressed` |
| M3 | Keyboard could zoom but not pan; arrows changed photo while zoomed | Fixed — arrows pan 40 px while zoomed; ← / → change photo only when not zoomed |
| L1 | Pan limit used the photo's own box, so a narrow photo could show black beside it | Fixed — limit = how much bigger than the visible area the zoomed photo is, per axis |
| L2 | A pinch during a pan left the dragging state on | Fixed — cleared before the early return |
| L3 | Mouse released outside the window kept panning | Fixed — a mouse move with no button ends the pan |
| L4 | A double-tap during the 0.2 s zoom animation anchors slightly off | Accepted — cosmetic, self-corrects on the next tap |
| nit | `.pvbtns` = the shared `.row` minus wrap | Fixed — uses `.row` |

Checked OK by the reviewer: a lone first tap never closes (the photo is excluded); `lastTap` resets on a new photo; no
stale swipe state; iOS double-tap page zoom excluded by `touch-action`; focus on open stays on Close; close / swipe /
pinch-cancel unchanged.
